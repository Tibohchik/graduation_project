# graduation_project
Сайт о глобальном потеплении: причины, последствия, статистика и простые шаги, которые может предпринять каждый.Рассказывает о причинах и последствиях изменения климата, показывает актуальные данные в виде графиков и даёт простые рекомендации, что может сделать каждый человек В нем будет разделы: «Причины», «Последствия», «Что делать», «Данные и источники». Онлайн графики и факторы.

>Цель проекта — предоставить пользователям достоверную, научно обоснованную и актуальную информацию о глобальном потеплении, его причинах и последствиях. Проект служит просветительской платформой, которая переводит сложные климатические данные на понятный язык. Он полезен для формирования экологического сознания, помощи школьникам и студентам в учебе
>Функции и Особенности - Актуальная новостная лента, разбор последствий для конкретных стран
