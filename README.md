# graduation_project
Сайт о глобальном потеплении: причины, последствия, статистика и простые шаги, которые может предпринять каждый.Рассказывает о причинах и последствиях изменения климата, показывает актуальные данные в виде графиков и даёт простые рекомендации, что может сделать каждый человек В нем будет разделы: «Причины», «Последствия», «Что делать», «Данные и источники». Онлайн графики и факторы
